## 2. Diagnostic exact de l'erreur `404` côté connecteur GitHub de ChatGPT

**Preuve technique (`gh api user/installations`) :**
```json
{
  "total_count": 1,
  "installations": [
    {
      "id": 180582722,
      "app_slug": "antigravity-for-github",
      "repository_selection": "all"
    }
  ]
}
```

### Cause exacte identifiée
1. **Aucune GitHub App tierce (ni connecteur ChatGPT / OpenAI) n'est installée sur le compte `naitconv-web`** : `user/installations` ne retourne qu'une seule installation (`antigravity-for-github`, créée le `2026-11-10T16:17:16Z`).
2. **Comportement standard de l'API GitHub sur dépôt privé :** Lorsqu'un connecteur externe (OAuth App ou GitHub App non autorisée sur ce dépôt privé) appelle l'endpoint `fetch_file` / `GET /repos/naitconv-web/agia-infrastructure/contents/...`, GitHub renvoie volontairement **`HTTP 404 Not Found`** (et non `403`) afin de ne pas divulguer l'existence d'un dépôt privé non autorisé.
3. **Impossibilité de correction depuis Antigravity :** Le jeton d'Antigravity (`antigravity-for-github`) ne peut ni installer une GitHub App tierce sur le compte `naitconv-web`, ni autoriser une connexion OAuth dans votre interface ChatGPT.
